# Simple Malware Analysis

A lightweight Python script for basic static malware analysis.

## Features

- MD5 and SHA256 hashing
- File entropy calculation
- ASCII string extraction
- Suspicious keyword detection
- URL extraction
- IPv4 address extraction
- Basic file type identification

## Requirements

- Python 3.x
- No external dependencies

## Usage

```bash
python malware_analysis.py suspicious_file.exe
```

Replace `suspicious_file.exe` with the path to the file you want to analyze.

## Disclaimer

This tool is intended for educational purposes and defensive cybersecurity research.

It performs basic static analysis and does not execute or modify analyzed files.

Detected indicators are heuristic and do not prove that a file is malicious.

Always use appropriate precautions when handling suspicious files.
